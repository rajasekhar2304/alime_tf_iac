### CAF (Cloud Adoption Framework) naming convention ###
<resource-type>-<workload/application>-<environment>-<region>-<instance>
Example: vm-webapp-prod-inc-001
vm: Virtual Machine (Resource Type)
webapp: Web Application (Workload)
prod: Production (Environment)
inc: India Central (Region)
001: First instance (Sequence)

## CHECK LOGS ARE COMING ##
AzureDiagnostics
| where TimeGenerated > ago(30m)
| order by TimeGenerated desc

## CHECK ONLY FIREWALL LOGS ##
AzureDiagnostics
| where ResourceType == "AZUREFIREWALLS"
| where TimeGenerated > ago(30m)
| project
TimeGenerated,
Category,
msg_s
| order by TimeGenerated desc

## VALIDATE INBOUND TRAFFIC ##
AzureDiagnostics
| where ResourceType == "AZUREFIREWALLS"
| where msg_s contains "10.48.3."
| where msg_s contains "10.49.1.10"
| project
TimeGenerated,
msg_s
| order by TimeGenerated desc

## Validate OUTBOUND Traffic ##
AzureDiagnostics
| where ResourceType == "AZUREFIREWALLS"
| where msg_s contains "10.49.1."
| project
TimeGenerated,
msg_s
| order by TimeGenerated desc
